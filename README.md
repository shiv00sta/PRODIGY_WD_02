# Prodigy InfoTech Web Development Internship - Task 02

## ⏱️ Stopwatch Web Application

A clean, responsive stopwatch web application developed using HTML5, CSS3, and vanilla JavaScript as part of the Prodigy InfoTech Web Development Internship track.

---

### ✨ Features
- **Accurate Timing:** Measures hours, minutes, seconds, and milliseconds.
- **Controls:** Start, Pause, Reset, and Lap recording.
- **Lap Tracking:** Dynamic list displaying split/lap times.
- **Responsive Design:** Optimized layout for desktop and mobile viewports.

---

### 🛠️ Tech Stack
- **HTML5** – Markup structure
- **CSS3** – Modern layout and dark UI styling
- **JavaScript (ES6)** – Timer logic and DOM manipulation
